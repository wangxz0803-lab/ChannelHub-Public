# v0.1.1 典型场景验收

验收日期：2026-10-10。结论：下述 19 组采数、网页下载和独立数值核验通过；本地完整回归 34 项通过，其中包含真实 RT 后端测试。这是明确场景和运行环境下的证据，不代表全部参数组合、第三方场景、完整 NR 协议或现网模型均已验证。

## 典型场景与复现

```bash
channelhub generate --config examples/typical-mimo-srs.json --output outputs/typical-run
```

也可在网页“高级配置”中导入该 JSON。该示例是通用 MIMO 波形探测实验，不定义完整的 NR 上下行调度流程。

| 配置 | 值 |
|---|---|
| 模型 | CDL-C，名义 RMS 时延扩展 100 ns |
| 载频 / 子载波间隔 | 3.5 GHz / 30 kHz |
| 网格 | 50 RB，600 子载波，8 时隙，112 符号，4 ms 观测窗口 |
| 天线 | 2 发 4 收，半波长间距、单极化全向阵列 |
| 接收端 | 初始坐标 (80,20,1.5) m，速度 (5,1,0) m/s |
| 有用发射 | 2 端口 SRS，C_SRS=12，B_SRS=0，Comb-2，48 RB 占用，偏移 1 RB |
| SRS 时间 | 周期 2 时隙、偏移 1；每次符号 12/13，重复因子 2；不跳频 |
| 干扰 | 一路满网格 QPSK（每时隙活跃概率 0.75）和一路同资源 SRS |
| 发射功率 | 有用 / 两路干扰分别 0 / -3 / -6 dBm，均为每活跃 RE 跨端口总功率 |
| 大尺度损耗 | 显式指定 110 / 111 / 112 dB，属于实验参数，不是由地理场景标定出的损耗 |
| 噪声 | -174 dBm/Hz，噪声系数 5 dB；理论每 RE 噪声功率 -124.2288 dBm |
| 随机种子 | 20261010～20261017，共 8 次独立生成 |

每份典型样本的 `H` 为 `[112,4,2,600]`，`X` 为 `[112,2,600]`，`Y` 为 `[112,4,600]`；有用 SRS 占用 2,304 个时间/频率 RE（按跨端口并集计数）。

## 验证方式与结果

从公开仓库取得初版代码，在不继承系统 site-packages 的全新虚拟环境中安装公开依赖。发现问题后安装修正版，重新核验输出，并重采受影响的 RT 场景。修正版安装包内容与提交的源码逐文件比对。运行环境为 Windows、Python 3.11.16、NumPy 2.4.6、PyTorch 2.9.1+cpu、Sionna/Sionna RT 2.2.0、Mitsuba 3.9.1、Dr.Jit 1.5.0。

19 组包括：8 个典型场景种子，重复采数、无干扰、无噪声、发射功率增加 6.0206 dB、静止接收端共 5 个对照，CSI-RS、SSB 参考信号、自定义 X 共 3 个波形变体，以及自由空间移动单径、地面反射、带两个干扰源的 MIMO 反射共 3 个 RT 场景。此外通过网页提交、预览并下载了一份相同典型配置，下载数组与脚本提交结果逐元素一致。

| 独立检查 | 实测结果 |
|---|---|
| 全部数据有限、维度/元数据/文件哈希匹配 | 19/19 通过 |
| 显式逐发射端口相乘求和，重算 Y | 最大相对误差 3.41e-16 |
| 从 CIR 和时延直接求和，重算抽样频点 H | 最大相对误差 3.64e-15 |
| SRS 长序列、循环移位及资源位置；CSI-RS Gold 递推独立核对 | 最大相对误差 1.46e-11；SSB 仅检查参考块占用与功率 |
| 所有生成波形的活跃 RE 跨端口总功率 | 与配置匹配 |
| 噪声功率与理论值 | 最大偏差 0.012 dB；实/虚方差及零均值检查通过 |
| 同配置重复 | 所有数组逐元素一致 |
| 关闭干扰 / 噪声 | 对应分量为零；其他随机分量保持不变 |
| 发射功率增加 6.0206 dB | 有用接收幅度乘 2；H、干扰和噪声不变 |
| 静止 / 移动 | 静止信道跨时间不变；移动时有相位变化 |
| 自定义复数 X | 上传、导出逐元素一致；不受生成波形功率/活跃概率设置改变 |
| RT 单径 Friis 幅度 | 最大相对误差 7.51e-7 |
| RT 单径传播时延 | 最大绝对误差 9.82e-16 s |
| RT 多普勒 | 理论 -115.0961397 Hz，实测 -115.0961538 Hz |
| 地面反射镜像法传播时延 | 最大绝对误差 9.19e-15 s |

导频参考依据：[TS 38.211 V15.7.0](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/15.07.00_60/ts_138211v150700p.pdf) 的 5.2、6.4.1.4 和 7.4.1.5。RT 理论核对使用阵列中心的几何距离、自由空间幅度、镜像反射路径和径向速度对应的多普勒。

相对误差定义为 `max(abs(actual-reference))/max(abs(reference))`。噪声和统计信道的数值范围仅描述这批随机样本，不作为跨平台逐比特承诺。

## 本次发现并修正的问题

1. **RT 路径时延的维度映射**：Sionna 的 synthetic-array CIR 包含天线维，而时延是 `[rx,tx,path]`。旧版按带天线维的方式索引时延，可能混用反射路径的时延，或在多发射源时失败。v0.1.1 先按发射源选出完整路径，再广播到天线端口。新增三发射源 MIMO 的独立几何时延回归，并补强单源反射时延检查。
2. **频率转换的中间精度**：原生 float32 时延先与复常数相乘会提前舍入，即使后续频率数组为 float64。v0.1.1 在相位计算前提升时延精度；新增宽带单径解析解回归。原生 RT 后端本身的精度仍由上游决定。

v0.1.0 的 RT 多径结果应重新生成。统计信道不受上述 RT 时延索引问题影响。

## 验证边界

本次验证覆盖前向传播和原始观测接口。统计链路独立、RT 使用固定几何路径上的多普勒演进；未验证多用户空间一致性、现网路径损耗标定、时域 OFDM/ICI、接收机、完整 SSB burst/PBCH 编码或下游算法性能。完整边界见 [数据接口](DATA_CONTRACT.md) 和 [README](../README.md)。
