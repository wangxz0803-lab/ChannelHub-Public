模型范围
  • CDL / TDL 使用官方 Sionna PHY，统计链路独立生成。位置用于自由空间路径损耗；可显式指定损耗。TDL 默认天线间独立，不使用方向图或阵列几何。
  • Sionna RT 使用实际路径损耗和绝对时延；短时间内固定路径几何，仅演进多普勒相位。
  • 频域 RE 模型采用时隙平均符号间隔，不包含时域 OFDM、CP、ICI 或同步接收机。
  • CSI-RS 支持单端口 row 2；SSB 包含同步序列和 PBCH-DMRS，不包含 PBCH 数据编码。更多波形可通过自定义 X 输入。
  • 自动波形功率是每个活跃 RE 上跨发射端口的总功率。它不是全载波总发射功率。
